# 構想 — neko-atlas(猫アトラス)

夏目漱石『吾輩は猫である』**一作**を、連載回・二声(地の文/会話文)・座談・配置・衒学の
五軸で解剖する静的 Web アプリ。目玉は全文を一枚に畳んだ**「応酬の帯」**。

- 名称案: **猫アトラス / `neko-atlas`**(別案: 聞き耳アトラス `kikimimi-atlas`、吾輩の耳 `wagahai-mimi`)
- カテゴリ: app-menu 📚 文学・翻訳(cat5)。makura / hojoki / tsurezure / jikenbo / ango-atlas の姉妹
- 本番: `neko-atlas.vercel.app`(想定)
- 対象: 青空文庫 夏目漱石(person148)所収『吾輩は猫である』。カード ID は L1 で実測して確定する

---

## 1. なぜ「一作だけ」がこの題材で効くか

フリートの literary atlas 群は多作品コーパス(ango 513 / kokoro 300)だが、随筆三部作
(makura / hojoki / tsurezure)は**一作を精密に解体する**型で成立している。『猫』は後者に属し、
しかも三つの外的性質が解析の足場になる。

1. **連載回と章はほぼ対応するが 1:1 ではない**(L1 実測 2026-08-25)。『ホトトギス』連載は
   **10 回**(1905 年 1・2・4・6・7・10 月 / 1906 年 1・3・4・8 月)、章は **11**。どの回が 2 章分を
   含むかを決められる出所を L1 では持たないため、対応表は `needs_review` のまま置く。
   第一回は読み切りのつもりで書かれ、実際に**第一章は 13,979 字と最短**(第二章 47,636 字の 3 割)。
   「第一章だけが他章から離れて布置されるか」という問いが**外的事実で答え合わせできる**
2. **分量の大半が会話文**。地の文(猫の語り・漢語と擬古的語法)と会話(口語・落語調)の落差が
   大きく、両者を分けること自体が主題になる。文体分析の常識(著者判別には地の文のみを使う)が
   ここでは前処理ではなく展示物になる
3. **筋が無い**。だから感情価曲線(kokoro-graph 型)は効かない。代わりに**語彙分散プロット**が
   そのまま構成図になる。プロット不在を欠点ではなく可視化の前提として使う

一作なので**全文をそのまま配信できる**(§4)。ango-atlas がベクトル圧縮と戦った予算問題が無く、
一形態素単位の精度に投資できる。これが設計上の中心的差分。

## 2. 検証オラクル(構想時点で先に置く)

| ID | オラクル | 性質 |
|---|---|---|
| **O-1** | **往復検査**: 青空文庫記法パース → 再直列化が本文領域と 100% 一致 | ラベル不要・厳密 |
| **O-2** | **直和分割**: 本文 = 地の文 ⊎ 会話文。文字数の総和が原文と一致し、鉤括弧の対応が閉じる(`『』` の入れ子・地の文中の引用を含む) | ラベル不要・厳密。**分離の正しさを字数の加算で縛る** |
| **O-3** | **話者帰属 gold**: 手ラベル 300 発話に対する規則ベースの適合率・再現率。**「帰属不能」を推定で埋めない**(null のまま出す) | 手作業・§5 の中心 |
| **O-4** | **連載回照合**: 章境界と初出 11 回の対応を 2 出所(初出誌の号・全集の解題)から取り、食い違いは evidence に理由を残す | 外的事実 |
| **O-5** | **二辞書照合**: 現代書き言葉 UniDic と 近代文語 UniDic の**両方**で解析し、差分の出た形態素を全件列挙する。結論を片方の辞書に依存させない | 二実装照合。tegaki-yomi / nanpure-forge / kasane-kairo と同型 |

O-5 は会話で挙がった論点(漢文訓読調の混在で結果が変わる)をそのままゲートにしたもの。
差分件数と差分箇所を成果物として出すこと自体が、この作品の混成性の測定になる。

## 3. 画面構成(6 ビュー・章 ID / 発話 ID / 形態素 ID を共通キーに相互リンク)

### 3.0 目玉 — 応酬の帯(`web/index.html`)

> **2026-08-25 設計改訂。** 当初は話者で塗り分ける「声の帯」だったが、L3 の実測で
> **話者が付くのは会話の 16.5% だけ**と分かった。帯の大半が「不明」一色になり構造が読めない。
> 一方で**交替の構造は 100% 正確に取れている**(鉤括弧の境界が証拠になるので帰属を必要としない)。
> そこで**誰が話しているかではなく、どう応酬しているか**を主たる符号化に変えた。

全文 **376,432 字**を、スケールごとに**符号化を変えた二段**で見せる。

**俯瞰(11 章 × 1 行・一画面)** — 1 px が覆う文字範囲について、
(a) 会話文字の比率を基調色に、(b) その範囲の**平均発話長**を明度に割り当てる。
長広舌が濃い塊として、短い応酬が淡い領域として現れる。**すべて集計値**なので、
発話が 1 px 未満(実測 0.6〜2.5 px)でもエイリアシングしない。

**詳細(章を開く・4 字/px で折返し)** — 地の文は地色、会話は**塊の中で濃淡を交互に振る**。
1 発話 ≒ 6 px なので縞が見える。26 連続の応酬は細かい縞、1,799 字の独白は一枚岩になる。
交互は「前の発話と話者が違う」ことしか主張しない — それは鉤括弧の境界が証明している。

**話者オーバーレイ(既定 OFF)** — 帰属できた 16.5% にだけ話者色を重ねる。
不明は**塗らない**(重ねないことで不明を示す)。凡例に帰属率と適合率を出す。

L3 実測が示した、この帯が描くべき構造:

| 章 | 会話率 | 塊長平均 | 塊内率 | 交替/千字 |
|---|---|---|---|---|
| 第 1 章 | 0.187 | 1.4 | 0.48 | 3.0 |
| 第 3 章 | 0.615 | 1.8 | 0.65 | 12.7 |
| 第 5 章 | 0.233 | 3.3 | 0.81 | 7.0 |
| 第 7 章 | **0.114** | 2.0 | 0.61 | 3.2 |
| 第 8 章 | 0.251 | 3.6 | 0.84 | 5.1 |
| 第 10 章 | 0.387 | **4.8** | 0.85 | 10.6 |
| 第 11 章 | **0.780** | 3.7 | **0.89** | 12.8 |

会話が「地の文に挟まれた単発」(第 1 章・塊内率 0.48)から
「切れ目のない応酬」(第 11 章・0.89)へ変わる。発話長は中央値 24 字・p99 363 字・最大 2,425 字で、
**短い応酬の海に巨大な独白が数個浮かぶ**二相構造。帯はこの二相をそのまま描く。

> **会話率は L4 で訂正した(2026-08-25)。** L3 の測定は章境界をまたぐ地の文セグメント(10 件)を
> 開始位置のある章に丸ごと計上していた。帯索引では境界で span を分割するので、上表が正しい値。
> 塊長・塊内率・交替密度は会話セグメントが境界をまたがないため変わらない。

### 3.1〜3.5 解析ビュー(会話の 5 手法に一対一対応)

1. **連載回クロノグラフ**(`chrono.html`) — 章 = 連載回を単位に MFW ベースの Burrows's Delta 距離行列
   + PCA 布置。第一章の孤立を検証する。rolling delta を重ね、**章境界と一致しない切り替わり**
   (執筆中断の跡)を探す。初出年月の帯を並置(O-4)
2. **二声**(`futakoe.html`) — 地の文 / 会話文を別コーパスとして対比。語種比率(和語・漢語・外来語 —
   UniDic の語種フィールドを使う)、文長分布のリッジライン、品詞バイグラム。
   **著者判別に地の文のみを使う理由**をこのページで実演する(会話混じりだと人物の口調を測ってしまう)。
   L2 実測 2026-08-25(L3 でルビ混入を修正して再測): 会話は本文内容の 46.1%。だが**章による振れが
   極端で、第一章 16.3% に対し第十一章 78.1%** — 座談が作品を乗っ取っていく過程がそのまま数値に出る。
   文長は会話文の方が長く(53.5 字 対 35.5 字)、文末表現は地の文「ある・居る・た・ない・だ」対
   会話「ね・だ・よ・さ・です」できれいに割れる。漢語比率は地の文 0.153 対 会話 0.125 で、
   猫の語りの方が硬い
3. **座談**(`zadan.html`) — 共起ではなく**応酬**のネットワーク(発話 i-1 の話者 → 発話 i の話者)。
   会話塊(地の文が N 字以上挟まらない連続発話)を単位とする。併せて章 × 人物の発話量積み上げ棒。
   迷亭の伸長、独仙の後半出現が形になる。**帰属不能の発話は「不明」ノードとして必ず表示する**
4. **配置**(`haichi.html`) — 語彙分散プロット。人物名・主題語の出現位置を全長軸に並べる。
   金田家の一件のような塊が挿話境界として立ち上がる。プロット不在の作品の「構成図」
5. **衒学カタログ**(`gendaku.html`) — 固有名詞・典故を抽出し **西洋 / 漢籍 / 同時代日本** に分類。
   章ごとの構成比を積み上げ面グラフに。分類は統制語彙による手作業で、**各語に出所を付ける**
   (自動推定で埋めない)。教養のひけらかしがどこで濃くなるかの定量化

### 3.6 リーダー(`reader.html?ch=&p=`)

全文をルビ付きで読む。話者色分け・典故注釈のポップオーバー・形態素ハイライト。
全ビューのディープリンク先であり、解析結果が本文のどこ由来かを常に確認できる場所。

## 4. 静的配信の見積もり(N-01 を守る)

| 成果物 | 見積もり | 方針 |
|---|---|---|
| 本文(原文 UTF-8) | 実測 376,432 字 ≒ 1.1 MB | 章単位 11 シャードで遅延取得 |
| 形態素解析結果 | 約 20 万形態素 → 10〜15 MB | 章単位シャード。表層・品詞・語種・lemma のみに絞る |
| 集計値(Delta 行列・分散・語種比・ネットワーク) | 数百 KB | 事前計算して一括配信 |
| 帯索引 | 実測 60 KB | セグメント列を列指向で(長さ/種別/塊 ID/塊内位置/話者) |

**初回表示は集計値+帯索引のみ**(1 MB 未満)。本文と形態素は開いた章だけ取る。
ベクトル検索を持たないので ango-atlas のような圧縮・量子化の戦いは発生しない。

## 5. 最大のリスク — 話者帰属

日本語小説の話者帰属は難しい。ここを機械任せにすると**結果全体が崩れる**(座談ネットワークも
配置ビューがこの上に乗っている。**応酬の帯は 2026-08-25 の改訂で帰属から独立させた** — §3.0)。
構想時点で以下を決めておく。

- 規則で拾えるものを拾う: 地の文の「主人が言う」「迷亭君が〜と云う」型、会話塊内の交替既定、
  一人称・文末表現の個人差(苦沙弥の「〜さ」、迷亭の駄洒落連結、独仙の漢語、三平の方言)
- 拾えなかったものは **null のまま出す**。UI に「不明」として表示し、率を明示する
- **手ラベル gold 300 発話**(章横断でサンプリング)に対して精度を測り、規則を較正する。
  gold は `data/speaker_gold.json` に判断根拠付きで残す
- 全発話の手作業補正は**やらない**(スコープ外)。「規則+gold 較正+不明の明示」で止める

これは推定で穴を埋めない方針(HC-012 と同型)。精度が出なければ座談ビューは章別発話量までに
縮退させ、応酬ネットワークは出荷しない — 縮退条件を SPEC に先に書く。

## 6. 前処理の決めごと(会話で挙がった論点を SPEC に固定する)

- **底本**: 青空文庫版。ルビ `《》`・傍点・入力者注 `［＃…］`・踊り字の処理方針を L1 で決め、
  `docs/notation_inventory.md` に**全件実測**で記録する。ルビを語彙統計に含めるか否かで結果が変わる
- **辞書**: 現代書き言葉 UniDic と 近代文語 UniDic の両方で解析し、差分を成果物に残す(O-5)
- **表記系**: 底本の表記系(新字新仮名)を単一の正とする。他の表記系の版・他作品を混ぜないので、
  表記系の統一問題そのものが発生しない。これは §1 の「一作に純化する」判断の副産物である
- **比較の単位は作品間ではなく作品内**: Delta も PCA も**章(連載回)と話者**を単位に取る。
  外部の基準点を持たない代わりに、11 章 × 十数話者という**内部の対照**で相対化する

## 8. スコープ外

- **『猫』以外の作品との比較**(漱石の他作品を含む)。本アプリは一作内部の解剖に純化する。
  外部コーパスとの Delta 比較・著者判別は、成立しても別プロジェクトとして切り出す
- 本文の校正・改変(取得したままを正とする。正規化は解析用の派生系統としてのみ持つ)
- 学術的な文体論・漱石論の**主張**(出すのは実測値と可視化まで。解釈は案内文の範囲)
- 全発話の人手による話者確定(§5)
- 英訳・対訳表示、挿絵の収載、ログイン・サーバーサイド機能
